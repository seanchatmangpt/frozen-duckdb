# Disruption Scorecard

Per-workload-class disruption measurement for the frozen-duckdb sovereign
engine against the warehouse sim (lane S5; extends the lane G5 economics
court, `warehouse-sim/economics/court.ts` — reused, not forked).

## Method

- **Path A (warehouse)**: real HTTP submit+poll against the local Next sim
  (`warehouse-sim`, Snowflake SQL API v2 surface, `/api/v2/statements`).
  Every poll is a real request; the sim's generated state machine
  (`nextState`, `POLL_INTERVAL_MS`) and generated ledger (`creditCost`)
  are imported directly — no fakes. Cold start is observed on iteration 1;
  the amortized p95 amortizes the cold window across all iterations. Both
  numbers are reported (cold-start amortization both ways).
- **Path B (sovereign)**: `warehouse-sim/economics/sovereign_probe` cargo
  fixture (standalone, outside the repo workspace) linked against
  frozen-duckdb, run with `--full` for the 5 workload classes; 50 measured
  iterations per class after 10 warmups, plus an observed cold run.
  Egress 0 B and invoice $0.00 by construction (in-process, nothing leaves
  the machine).

## Workload classes

| id | class | SQL shape |
|---|---|---|
| point-filter | point filter | single-row `event_id = 90000` select |
| grouped-aggregation | grouped aggregation | two-stage GROUP BY over per-case rollup |
| windowed-rolling-avg | windowed rolling avg | 50-row window OVER (PARTITION BY case_id) |
| cohort-retention-journey | cohort retention journey | first-event cohort join + per-step DISTINCT retention |
| ocel-rehydration | OCEL rehydration | full 100k-row ordered event-stream drain |

## Disruption assertions (per class)

- **F1 latency**: sovereign p95 <= 0.05x warehouse amortized p95.
- **F2 egress**: sovereign bytes <= 0.01x warehouse bytes.
- **F3 invoice**: sovereign invoice === $0.00 exactly, with nonzero
  counterfactual credit burn on the sim ledger.

F1/F2 that do not clear are recorded as **honest-negative (NEG) rows** with
the real measured ratio — the ratio is reported, never tortured to fit.
F3 is a hard fence; a nonzero sovereign invoice fails the run. The
non-vacuity selftest (`scorecard.ts --selftest`, exit 3) proves the
assertion machinery refuses a doctored sovereign leg.

## Running

```bash
bash warehouse-sim/economics/run_scorecard.sh
# -> warehouse-sim/economics/.evidence/disruption_scorecard.json
# -> warehouse-sim/economics/.evidence/disruption_scorecard.md
```
